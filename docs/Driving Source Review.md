# Remaining driving jurisdiction source review

Checked November 12, 2026. Each of these 28 additions has four selected lessons and eight original questions. This completes jurisdiction-specific introductory availability for all 50 states and DC, not complete handbook or knowledge-test coverage.

The source inventory was recorded before course data assembly. Specific source sections, review limits and available file hashes are retained in the catalog. Direct PDFs were reviewed locally; publishers' manuals, artwork and test questions are not redistributed. For sources unavailable as complete downloads, the review uses the official publisher's research-reader text. No missing content or revision dates were inferred.

## Boundaries

- New Hampshire and Nevada use official DOT roundabout guidance. DC uses selected DDOT speed, attention and visibility guidance. These are not full driver manuals.
- New Mexico uses the officially linked file named ver11.19.19. South Carolina uses the accessible official legacy PDF. Wyoming's official directory still links the August 2021 manual. Only the selected enduring principles were added; newer licensing or law details are not implied.
- Mississippi's downloaded cover says December 2024, although the official file is served under a January 2025 name. South Dakota's PDF says November 2024; its official directory was updated July 2026. Edition dates and directory dates are kept distinct.
- West Virginia's July 2026 cover and fog section were visually checked because parts of its extracted text use a custom character encoding.
- Local signs and controls determine the actual route. A generic roundabout lane diagram is not a substitute for posted lane assignments.
- The special Minnesota two-large-vehicle yield rule and North Carolina rail stop range are mapped to their cited manual sections. No state rule was inferred from another state.
- NOAA's fog guidance supplies the additional physical explanation about high-beam glare in the Wyoming topic.
- Review latest laws, remaining handbook objectives, licensing requirements, full exam blueprints and practical driving with a qualified instructor before any completeness claim.
