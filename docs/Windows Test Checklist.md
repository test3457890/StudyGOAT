# Windows owner test checklist

Use this during the November 25, 2026 or later Windows testing session. Record the date, browser, URL or local file, result, and a screenshot or short error description for each failure. Do not mark a feature passed because it appears in source code or an automated test.

## Setup and recovery

- [ ] Open the GitHub Pages version in current Firefox and Chrome or Edge on Windows. Confirm images, links and all eleven repository screenshots load.
- [ ] Download `StudyGOAT.html`, open it from disk, and try the offline study features. Note which AI and sync functions require network access or configuration.
- [ ] Save a Settings backup, add a harmless test class and topic, reload, export the offline HTML, and restore the backup in a separate browser profile. Confirm progress and source data survive. Clear only the disposable test profile afterward.
- [ ] Import a backup from a trusted source with an invalid custom ID. Confirm the menu warns, valid study areas remain usable, and the original backup remains available. Do not import unknown personal files into a public demonstration.

## Every main workflow

- [ ] Open each class, certification, and driving state directory. Search for a course and a missing course. Check category filters, state names, abbreviations, and the partial-content labels.
- [ ] In a representative built-in course and a disposable custom course, open every navigation button: Topics, Learn, Videos, Tutor, AI Builder, Play, Quiz Prep, Mixed Quiz, Practice Test, Mistakes, Test Review, Add docs, Settings, and Menu. Record disabled or configuration-dependent functions.
- [ ] Practice one correct and one wrong answer, typed answer where available, lesson steps and completion, quiz group creation and editing, timed exam submission and timeout, and mistakes review. Reload and check saved progress.
- [ ] Play one full round each of Flashcards, Learn, Match, Blitz, and Lightning. Check selection, keyboard shortcuts, scoring and persistence.
- [ ] Open a source register, a saved study path, the Technician question pool and full practice exam, and one driving test state. Verify that partial content and simulated exercises are labelled accurately.
- [ ] With a configured AI provider only if you choose to use one, try tutor chat, a small AI Builder proposal and cancellation, document upload, and a test review. Verify the proposed content before applying it. Never place an API key, private document, or real graded test in a public issue or screenshot.

## Usability and evidence

- [ ] Test keyboard Tab and Enter navigation, answer shortcuts, screen reader labels, zoom at 200%, narrow browser width, and browser Back/Forward behavior.
- [ ] Try empty searches, invalid answers, unsupported uploads, missing AI configuration, and a cancelled operation. Record whether errors explain recovery.
- [ ] Capture authentic screenshots of the desktop menu, one class home, quiz feedback, a source screen, a game, Settings, and a narrow layout. Remove names, grades, keys, and private files before sharing.
- [ ] Compare visible results to the README feature list. Report the exact browser and steps for any discrepancy.

Automated content and browser checks are separate from this owner session. No boxes above are pre-checked.
