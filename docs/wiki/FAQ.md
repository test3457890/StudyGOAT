# Frequently Asked Questions

## Who can use StudyGOAT?

StudyGOAT is designed for students, working professionals, self-directed learners, and people studying for certifications.

## Is StudyGOAT only for college classes?

No. The built-in content covers two university courses and five partial introductory study tracks, but the application includes a custom course builder that can support other topics when a suitable AI connection is available.

## Does StudyGOAT come with official certification courses?

No. The five new tracks are independent, partial study slices. None is an official certification course. Users should build their study plans around the provider's current exam objectives and authorized materials.

## Does it guarantee a passing grade or certification?

No. StudyGOAT provides practice and review tools, not a score guarantee, credential, or official examination.

## Does it need an internet connection?

Many built-in study activities can run locally from the HTML file. External fonts, optional AI services, and cloud-specific functionality require network access or a supported environment.

## Do I need an AI API key?

Not for the included built-in study activities. AI-assisted tutoring and course building need an available provider, which might require your own API key.

## Where is my progress stored?

In the current public browser deployment, progress is stored in the browser's local storage. Clearing browser data can erase it. Browser profiles and devices do not automatically share local progress.

## Can I use employer training materials?

Only if you have permission. Do not upload confidential business information, restricted documents, or personal data to an AI provider.

## Is StudyGOAT an official exam prep product?

No. StudyGOAT is an independent study companion and is not affiliated with certification organizations unless otherwise stated.

## Can I report an incorrect question?

Yes. Open an [issue](https://github.com/test3457890/StudyGOAT/issues) with the question ID, track version, problem and a reliable correction source.

## Is the code open source?

The GitHub repository is public, but it currently does not contain a software license. Viewing code publicly is different from receiving an open-source reuse license.
