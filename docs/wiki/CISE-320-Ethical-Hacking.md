## Study in the app

1. Read the assigned chapter and open its matching **Topics → Learn** lesson. Use **Read this step** if listening helps.
2. Answer the chapter's **Practice** questions, then review explanations and save a mistake note when needed.
3. Use **Play → Recall Sprint**, **Today** and **Build exam** to review multiple chapters. Your progress saves in the browser.
4. Use **Settings → Download my progress (.json)** to keep a private backup before moving between devices. [Illustrated download and study guide](https://github.com/test3457890/StudyGOAT/blob/main/docs/Download%20and%20Study%20Guide.md).

For hands-on work, use only systems and targets you are authorized to test. Check Canvas for which chapters are assigned and bring instructor-approved quiz screenshots or notes to improve coverage and format. Report errors using the app's **Feedback** view or the repository issue templates.
