# Welcome to the StudyGOAT Wiki

StudyGOAT helps you turn study time into useful practice.

Whether you are preparing for a college exam, reviewing material after class, learning a new technical skill, or working toward a professional certification, StudyGOAT gives you a focused place to learn, practice, and see what needs more work.

StudyGOAT is a browser-based study application with lessons, quizzes, exam practice, flashcards, games, and progress tracking. Some features work directly in the browser. AI tools are optional and need a supported connection.

## Who is StudyGOAT for?

### Students
Review course topics, learn step by step, practice questions, and prepare for quizzes or exams.

### Professionals and certification candidates
Organize the topics you need to study, practice terminology, identify weak areas, and build a review routine around your study materials. Custom AI-assisted course building requires configuration and should be checked against official exam objectives.

### Educators and contributors
Explore how StudyGOAT organizes courses and study activities. Help improve accuracy, clarity, accessibility, and the learning experience.

## Current project status

StudyGOAT is an early, functional browser application. Its source code includes two university courses plus nine sourced study tracks with partial coverage, 103 lessons and 444 original questions. Study activities, progress tracking and optional AI tools for university/custom courses remain available. The availability of AI features depends on how the program is opened and which AI provider has been configured.

The [roadmap](https://github.com/test3457890/StudyGOAT/wiki/Roadmap) separates existing capabilities from proposals. A public GitHub repository does not automatically mean the GitHub Pages website is live.

## Important information

StudyGOAT is an independent learning tool. It is not endorsed by any school, employer, certification organization, or exam provider unless explicitly stated otherwise. It does not guarantee a passing grade or certification. Always confirm requirements with your professor, employer, or official exam provider.
