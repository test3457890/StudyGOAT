# All State Driving Prep

Updated November 12, 2026. All 50 states and DC have separate selected study material. This is introductory availability, not complete permit-test coverage.

## What is available

The 28 new jurisdiction courses each contain four selected lessons and eight original questions. The earlier 23 state courses retain their existing content. Every course includes source references, a coverage notice, flashcards, short practice, mistake review and local progress. The national safety bank remains available everywhere and is counted only once.

Open Driving Tests, search the state name or abbreviation, then choose its course. The directory now links directly to an official source for the selected topics. Local controls, the complete current manual and current law remain authoritative.

The new material covers selected roundabout/intersection conflicts, rail warnings and clearance, lane changes, visibility, fatigue and road sharing. It does not cover the full handbook, all traffic laws, the complete exam blueprint or road-test skills. No official test questions or manual illustrations were copied.

## Source limits and remaining work

New Hampshire and Nevada additions use DOT roundabout guidance; DC uses DDOT safety guidance. New Mexico, South Carolina and Wyoming include older or undated official baselines. Directory update dates are not treated as manual revisions or law effective dates. Source access and edition limits are explicitly retained.

The repository [Driving Source Review](https://github.com/test3457890/StudyGOAT/blob/main/docs/Driving%20Source%20Review.md) lists all 28 new source baselines and the available file fingerprints. West Virginia's cover and fog section were visually checked because its text extraction contains custom font encoding.

Still needed in every jurisdiction: remaining manual objectives, current permits and graduated-license requirements, law/edition reconciliation, a full test blueprint, more varied scenarios and independent instructor review. Supervised practical driving cannot be replaced by these browser lessons.
