# Getting Started

StudyGOAT is designed to be straightforward. You can use the built-in study features without installing a package manager or setting up a server.

## Open the application

Option 1: Download the source from the [StudyGOAT repository](https://github.com/test3457890/StudyGOAT) keep the `courses` folder beside the HTML file, and open `StudyGOAT.html` in a modern browser.

Option 2: After GitHub Pages has been enabled and deployed, open https://test3457890.github.io/StudyGOAT/.

The repository is public, but GitHub Pages requires a separate deployment setting.

## Your first study session

1. Open StudyGOAT.
2. Choose a course on the main menu.
3. Select Learn to work through a topic or Practice to answer questions.
4. Open Play to try flashcards or other study games.
5. Check Mistakes or Weakest Topic to focus on what you missed.
6. Use Quiz Prep or Exam when you want a more structured review.

The included source currently has built-in content for CS 315 (data structures and algorithms) and CPSC 222 (discrete structures). These are examples of the application's course-based layout, not a complete catalog of subjects.

## Professional or certification study

Five partial introductory tracks are now included without AI. Use Sources & coverage to check the boundaries. For additional custom subjects, see [Custom Courses](https://github.com/test3457890/StudyGOAT/wiki/Custom-Courses) and [For Certifications](https://github.com/test3457890/StudyGOAT/wiki/For-Certifications). Course generation requires an available AI provider. None of the new tracks is an official or complete certification curriculum.

## Your progress

StudyGOAT stores local progress in your browser by default. Different browsers and devices do not automatically share local progress. Clearing browser data may remove it. Look in Settings for available backup and export tools.

## AI is optional

Core built-in learning and practice features do not need an API key. AI tutoring, material analysis, and course building depend on an available AI integration. Read [AI, Privacy and Data](https://github.com/test3457890/StudyGOAT/wiki/AI-Privacy-and-Data) before using those features.
