# Contributing to StudyGOAT

StudyGOAT is a public GitHub project. Feedback from students, educators, professionals, and developers can help make the study experience clearer and more reliable.

## Ways to help

- Report bugs or incorrect answers.
- Suggest easier explanations and accessibility improvements.
- Propose improvements for custom course creation.
- Suggest study features for certification candidates.
- Submit code changes through a pull request.
- Improve documentation and examples.

## Before opening an issue

Search existing [issues](https://github.com/test3457890/StudyGOAT/issues). If you do not see your topic, open a new issue with:

1. A short title.
2. What you were trying to do.
3. What happened and what you expected.
4. Your browser and operating system if relevant.
5. Safe reproduction steps or a screenshot without private information.

For content accuracy reports, include the topic, question, what looks incorrect, and a trustworthy reference.

## Code contribution flow

1. Fork the repository or work on an approved branch.
2. Make a focused change.
3. Check JavaScript syntax and test the changed feature in a browser.
4. Confirm that existing study modes still work.
5. Open a pull request with a short explanation and your test results.

Read the embedded build specification in `StudyGOAT.html` before changing course-generation formats.

## Content and security rules

- Do not submit API keys, passwords, student data, private employee information, or confidential company files.
- Do not include leaked exams, exam dumps, or other materials you lack permission to redistribute.
- Verify questions and explanations before proposing them as reference content.
- Keep instructions clear, friendly, and accessible.
- Do not make claims of official certification endorsement without authorization.
