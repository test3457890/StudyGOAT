# Saved study paths

Open a course, then choose Open saved study path. Each assignment links to the official reading and any implemented lessons and practice. Marking a row records your own reading/preparation and saves it with existing progress and Settings backups. It does not grade the assignment or award official credit.

The five study programs have routes for every listed objective, task, chapter, module or published radio group. All 50 states and DC have 13-area official-manual checklists. Missing built-in instruction remains explicit; an official reading link is not counted as a new authored lesson.

Technician group assignments link both guided lessons and the exact NCVEC group practice. FAA assignments list every printed knowledge code in the task. CAP includes the 16 leadership chapters and seven Aerospace Dimensions module reading assignments. WFA rows are follow-up with the actual provider, not medical skill sign-off.

Reading checks are separate for each course. Clearing browser storage can remove them, so use Settings backups before changing devices. Offline exports retain built-in lessons and checklists, while opening an external official reading still requires an internet connection.
