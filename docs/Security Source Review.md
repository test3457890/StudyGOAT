## Content and controls

The expansion adds 18 topics, 36 lessons and 108 original multiple-choice questions, producing 50 lessons and 172 original questions for Security+. Each new topic contains principles, an explicit procedure, a fictional worked scenario and six questions with explanations. All 28 objective entries have partial status, mapped topics and specific remaining work.

The original access-review exercise tests four roles against a stated 16-setting permission matrix. It has no external side effects and makes no claim to reproduce a CompTIA performance-based question. Objective practice filters individual questions by objective tags and uses distinct item IDs. The short mixed test retains its existing unweighted foundation-practice behavior, with no full-exam blueprint claim.

Existing course IDs, original Security+ topics and questions, other sourced tracks, university models/topics and the separate NCVEC pool must remain intact. Content checks validate the map and counts, browser checks exercise all 28 scoped practice entries and access-review feedback, and the pool check independently compares all 409 NCVEC questions with the retained source PDF. GitHub Actions must pass before merge. Release PRs record publication and live verification evidence.
